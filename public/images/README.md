# Product images

Place image files here. They are served at `/images/<filename>`.

**Required for current products** (see `src/data/sneakers.ts`):

- Puma ST Runner v4:  
  `Puma-ST-Runner-v4-Mesh-Sneakers-1.jpg`, `Puma-ST-Runner-v4-Mesh-Sneakers-2.jpg`,  
  `Puma-ST-Runner-v4-Mesh-Sneakers-3.jpg`, `Puma-ST-Runner-v4-Mesh-Sneakers-4.jpg`

Filenames are case-sensitive. If a file is missing, the app shows a fallback placeholder.
